## 一、目标

甲方没有单列无障碍条目，但 §4D 的 focus 态、§4E 的逐态走查和 Storybook a11y addon（`test: "error"`，STORYBOOK.md §三）让它成为硬门禁：一处违规，story 就红。

## 二、无障碍与语义规范

- 一页一个 `h1`，区块用 `section` + `aria-labelledby`。
- 颜色对比 AA；图片 alt 来自数据。
- 键盘走通全页：导航、抽屉、手风琴、轮播、BMI 表单。

## 三、补充约定

- 可交互元素必须是原生可聚焦元素，禁止 `div onClick`（COMPONENTS.md §三 第 5 条）
- 图标一律 `aria-hidden`，含义由旁边文本或 `aria-label` 承担（COMPONENTS.md §三 第 6 条）；证言卡社交图标按 PROJECT §11 #1 为纯装饰
- focus-visible 样式：全站统一 2px 强调色外环 + 2px offset（MOTION.md §二 状态规则 2）
- 移动抽屉打开时焦点进入抽屉、Esc 关闭、关闭后焦点回到触发按钮

## 四、待实现 / 已知问题

- 键盘走通全页的手测清单待区块完成后列出

## 测试记录

- 2026-09-17 P4：79 原语 stories × 2 视口共 158 次 axe 检查为零违规，未 disable 规则。18 个 Playwright 测试覆盖 disabled / 真实链接、Tab / Space / Enter / radio 方向键、数字字段描述与无效态、details、轮播边界 / 屏外 inert、跑马灯暂停 / OS reduce。禁用 NumberField 只淡化 input，单位仍 AA 可读；空 Carousel track 明确 group 角色且不加入 Tab。
- 跑马灯 Pause / Resume 使用随动作改名的普通按钮，不混用 `aria-pressed`，依据 [W3C Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/)。Chip 的 toggle 名称保持不变并使用 aria-pressed。
- axe 与浏览器可访问树检查不等于读屏软件实听；VoiceOver / NVDA 与全页键盘走查仍待 P5/P7。
